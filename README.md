# WealthAdvisor - Wealth Forecaster

A modern, interactive financial forecasting tool designed to help you model your wealth accumulation over time. Built with a sleek Glassmorphism UI, it provides real-time visualization of your net worth based on income, expenses, and investment growth.

## Features

-   **Interactive Wealth Chart**: Visualize your net worth trajectory over 20 years.
-   **Singapore Income Tax Included**: Accurate automatic tax calculation based on Singapore Resident Income Tax Rates (YA 2024 onwards).
-   **Dynamic Expenses Tracking**: granularly add and remove monthly expenses to see how your lifestyle choices strictly impact your long-term wealth.
-   **Growth Levers**: Experiment with:
    -   Stock Market Returns & Dividend Yields
    -   Annual Raises & Bonuses
    -   Savings Logic derived from Net Income and Real Expenses.
-   **Responsive Design**: A beautiful, dark-themed UI built with Vanilla CSS and HTML5.

## Installation & Usage

1.  Clone the repository:
    ```bash
    git clone https://github.com/raminetinati/WealthAdvisor.git
    ```
2.  Open the project folder.
3.  Open `index.html` in your web browser.

## Technologies

-   **Frontend**: HTML5, CSS3 (Custom Variables, Flexbox/Grid), JavaScript (ES6+).
-   **Visualization**: [Chart.js](https://www.chartjs.org/).
